The dataset ZIP is 5,289,108,314 bytes and its central directory is about 847 MB.
`audit_osiris.py` reads only the first 1 MiB of that directory and selected small
text entries; its dataset inventory is explicitly partial. It fully inventories
the much smaller code directory and samples the main script, configuration and
Apache license. The sampled workflow uses PPO. The Hugging Face card metadata
states Apache-2.0 while its body also mentions CC-BY-4.0; reconcile dataset rights
before redistribution or training. Code and data licensing should be handled
separately. Nothing downloaded is executed by the audit.

Run `python audit_osiris.py --output results/data-audit/new-audit` to repeat the
bounded audit. It pins the observed revision, checks exact HTTP ranges and hashes
local files. Shared datasets under /data/db remain untouched.

## Measured synthetic pilot

`verified_dataset.py` generates 12 current-mirror geometries at 10/20/30 µA:
36 design/operating-condition cases, not 36 distinct topologies or geometries.
Every case retains actual GDS, SPICE, Magic DRC, Netgen LVS and nine
capacitance-extracted corner/temperature measurements. The pilot contains
324 corner/temperature simulations. Geometry and performance are generated by
tools, not guessed by a language model. Failed specifications remain useful
negative labels. This is a single upstream GLayout topology and captures its
biases; it is not a representative human-layout corpus.

Source/PDK provenance, GDS hashes and raw evidence accompany measurements.
The RL loader checks complete grids, layout hashes, split/current consistency,
candidate geometries, simulation coverage and aggregate copy-error labels.

High-quality expansion needs circuit families (mirrors, differential pairs,
OTAs, references), meaningful legal variations, independent verification,
full RC, mismatch labels, raw failures, generator/model hashes and reproducible
seeds. Split by circuit family/topology and design lineage before training:
near-duplicate layouts must not span train and test. Review selected cases with
an experienced designer. Variation count alone is not data quality.

## RL pilot and its boundaries

`rl_search.py` implements REINFORCE with a two-layer 64-unit tanh network.
An action chooses an unqueried candidate. Observations contain the goal,
current, progress, best observed metrics and candidate geometry. Queried actions
are masked. Rewards combine improvement in penalized area/specification score
and terminal feasibility. This is sequential sizing/acquisition, not transistor
placement, routing or arbitrary netlist synthesis.

Training uses only 10/20 µA measurements and randomized specification targets.
30 µA labels are used only by the evaluation environment. All methods share four
initial candidates and eight total evaluation queries. Three model seeds each
train for 1,000 episodes: 24,000 total cached training oracle lookups, plus the
physical cost of making the dataset. Random and Bayesian baselines do not incur
that training cost. Evaluation tasks repeat across models and are correlated.

The first result: RL 141/150 successful evaluations, random 135/150, Bayesian
141/150. Mean best penalized scores (lower is better): 0.45454, 0.47694, 0.41540.
All conditional median feasible areas were 149.7258 µm². This does not demonstrate
RL superiority; Bayesian optimization performed better on the average score.
No significance or cross-topology generalization claim is made.

Use `sbatch scripts/run_dataset_rl.sbatch` to regenerate data, train, evaluate
and test. The pilot is small enough for CPU. GPU scaling becomes useful with
larger graph/spatial encoders and parallel live-tool environments; it does not
accelerate these serial verification tools automatically.

## RC and mismatch probes

`rc_probe.py` uses Magic detailed resistance extraction with resistance and
delay cutoffs disabled. It requires emitted-net coverage for all four mirror
nets plus actual resistor/capacitor evidence. The default delay cutoff initially
emitted only bulk resistance; that run is exploratory evidence, not full RC.
The corrected W=2/L=1.5 run emitted 755 resistors and 76 capacitors and simulated
nine corners/temperatures. Comparison against another extraction engine and
independent topology/device-parameter checks are still outstanding.

`mismatch_probe.py` enables the PDK's MC_MM_SWITCH/AGAUSS definitions. A control
driver seeds Ngspice before sourcing the circuit. It requires identical seeded
repeats, visible mismatch between identical devices, exact matching with mismatch
disabled, and seed-invariant disabled mirror measurements. Earlier attempts
that failed reproducibility are retained and must not be used for yield claims.

The first successful probe sampled 50 seeds at TT/27°C, 20 µA with full experimental
RC. 37/50 met the 5% DC copy-error bound over 0.6–1.6 V: observed fraction 74%,
Wilson 95% interval approximately 60.4–84.1%. This is not production yield:
no bandwidth, process Monte Carlo, spatial gradients, foundry validation or
silicon measurements are covered. It shows a gap hidden by deterministic
corner checks, and motivates including robust performance in the reward.

A second design (W=4 µm, L=2 µm) passed 80/100 seeded TT/27°C DC samples,
Wilson 95% interval approximately 71.1–86.7%. On the shared first 50 seeds it
passed 39/50 versus 37/50 for the smaller design. The modest improvement does
not resolve the robustness gap; both designs need further optimization and
more complete statistical/electrical coverage.

Reproduce with `sbatch scripts/run_rc_probe.sbatch <verified-design-folder>`,
then `sbatch scripts/run_mismatch_probe.sbatch results/rc-probe-<job-id> 100`.
Wait for extraction to complete or use an afterok Slurm dependency.

## Next decisions

First validate RC against a trusted CAD flow and expand statistical coverage.
Use the mismatch controls for every new model/PDK version. Collect broader
verified families and enough failure cases before scaling neural training.
Benchmark RL against Bayesian search and constrained optimizers at matched
query budgets, with training costs visible. For physical layout RL, use legal
placement/finger/routing actions and verified extracted performance as reward;
start from a generator-supported circuit and inspect the legality/action space.
Cadence/Synopsys integration and foundry signoff need the university's licensed
installation, PDK libraries and approved decks. Those are still unavailable on
this environment's PATH; they cannot be replaced by more training.
